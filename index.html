RESEARCH PIPELINE

How segmentation works

01 / Select slices

Choose three consecutive axial FLAIR slices from one MRI volume.

02 / Preprocess

The API converts images to grayscale, scales them to the model input size and builds a three-channel tensor.

03 / Predict

The pretrained U-Net estimates the FLAIR abnormality mask for the middle slice.

04 / Review

Inspect the predicted binary mask alongside the target MRI slice.

05 / Evaluate

Use separate expert labels and held-out cases for meaningful Dice and IoU evaluation.
